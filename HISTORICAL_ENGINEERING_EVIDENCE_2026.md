## Core and agent architecture — evidence discipline

OMS IT's records describe core-system/agent-oriented architecture and workstreams involving research, orchestration, operational modules and QA. Modules such as staff/HR, CRM, support, projects, marketing, training, documents, settings and audit should **not** automatically be called independently running AI agents. The internal Agent Evidence Register classifies entries as **Declared → Implemented → Integrated → Tested → Deployed → Production → Verified**.

**A deduplicated, end-to-end verified count of active production agents has not been established for public release.** Historical architecture targets, agent names in documents, and module counts are not production metrics.
