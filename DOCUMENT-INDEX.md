## Evidence policy

Public claims should identify the evidence source and date. Private Partner Portal content, access credentials, session data, customer-confidential information, unnecessary personal information, and restricted documents must not be published.

Self-published GitHub material is supporting public evidence, not a substitute for issuer-controlled verification. Where an OpenAI-controlled public source exists for a claim, that source should take precedence.
