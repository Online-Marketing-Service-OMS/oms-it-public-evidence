# Security & Redaction Policy

This repository is intended for public-safe evidence only.

## Never publish

- passwords, API keys, access tokens, cookies, or session identifiers;
- login links containing private tokens;
- private Partner Portal data unrelated to the public claim;
- confidential agreement contents;
- customer-confidential information;
- private infrastructure details;
- unnecessary personal email addresses, phone numbers, or account identifiers;
- signatures or other personal identifiers unless publication is clearly authorized and necessary.

## Redaction standard

Before adding screenshots, letters, emails, PDFs, or portal captures:

1. keep the organization name, issuer, date, relevant status/tier, and claim-supporting text visible;
2. redact unrelated personal data and account details;
3. crop away browser tabs, unrelated services, bookmarks, and local-machine information where possible;
4. preserve enough visual context to show the first-party domain or document origin;
5. do not edit wording that materially changes the source meaning;
6. label each public copy as a redacted public-safe copy where applicable.

## OpenAI evidence handling

The OpenAI Partner Network evidence in this repository should be used only to support the exact organization-level status claim documented in `OPENAI_SELECT_PARTNER.md`.

Do not publish restricted partner materials or confidential program documents solely for the purpose of proving public status.
