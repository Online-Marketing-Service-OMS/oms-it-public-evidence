## Source integrity

For file-based evidence supplied for review, structured records may preserve a SHA-256 hash of the reviewed source file. For issuer-originated email evidence, the public record preserves the sender domain, subject, date, scope, and source-handling note while the original message remains privately retained by OMS IT.

## Evidence classes

### Class A — Issuer-controlled public evidence
Official public webpage, directory, profile, or public record controlled by the issuing organization.

### Class B — Issuer-controlled authenticated evidence
Authenticated first-party portal records, such as `partners.openai.com`.

### Class C — Issuer-originated documentary evidence
Letters, emails, notices, or approved communications received from the issuing organization.

### Class D — OMS IT public evidence record
Redacted copies, structured summaries, metadata, cryptographic hashes where applicable, and claim-boundary documentation maintained in this repository.

### Class E — OMS IT statement
Statements published on OMS IT-controlled websites, GitHub repositories, social channels, or press releases.

## Publication rule

A Class D or Class E source should not be described as stronger independent verification than Class A, B, or C evidence.

No sensitive portal data, login information, session identifiers, private customer information, confidential agreement contents, or unnecessary personal information should be published.
