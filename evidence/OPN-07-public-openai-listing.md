# OPN-07 — OpenAI Partner Locator Eligibility Clarification

**Evidence class:** Issuer-originated documentary evidence  
**Source:** OpenAI Partner Marketing `<partnermarketing@openai.com>`  
**CC:** OpenAI Partner Support `<partnersupport@openai.com>`  
**Date:** 5 October 2026  
**Subject:** `Re: Partner Locator Listing Request — OMS IT / Online Marketing Service — OpenAI Select Partner`

## Evidence summary

OpenAI Partner Marketing explained that the public Partner Locator is reserved for **Advanced** and **Elite** partners as a benefit of those tiers.

The same message states that **new Select partners are not automatically listed** and would need to progress to the Advanced tier before being added to the Partner Locator.

It also notes that a small number of Select partners may still appear as exceptions because they were early partners from the 2025 program year.

## Why this matters

The absence of OMS IT from the public Partner Locator should therefore **not, by itself, be treated as evidence that OMS IT is not a Select Partner**. According to the issuer-originated clarification, public Locator inclusion is not automatic for new Select partners.

## Claim supported

This evidence supports the narrower statement that OMS IT's lack of a public Partner Locator profile is consistent with OpenAI's stated Locator eligibility rules for new Select partners.

It does not create a public OpenAI-hosted OMS IT profile, and it should not be presented as a substitute for an OpenAI-controlled public listing if one becomes available in the future.
